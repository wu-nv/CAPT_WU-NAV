📖 操作指南（点击展开 / 收起） ▶

① 本船操纵

· 输入 HDG / SOG / COG 后点【应用参数】生效

· 或点 左5° 右5° 等按钮逐度调整

· 键盘：← → 转向，↑ ↓ 变速

② 雷达控制

· 量程：切换显示范围（0.5~24 海里）

· 增益：回波亮度，太大杂波多

· 雨雪 / 海浪：抑制背景杂波

· 暂停扫描：停止天线旋转

③ EBL / VRM（黄色圆+线）

· 鼠标 / 手指按住雷达区拖动：改变 EBL 方位

· 拖到 VRM 圆附近：改变 VRM 距离圈

· 读数显示在画布左下角

④ 显示与模式

· 向上基准：首向上 / 北向上 / 航向向上

· 运动模式：相对运动 / 真运动

· 矢量类型：相对矢量（虚线）/ 真矢量（实线）

· 矢量时间：1~12 分钟，决定矢量长度

⑤ 目标管理

· 输入距离 / 方位 / 航向 / 航速 → 【添加运动目标】

· 或点【随机添加】快速生成

· 点列表项：选中（黄框）

· 点列表 ✕ 或 选中后点【删除选中目标】

· CPA / TCPA 实时更新，危险时闪烁报警

⑥ 固定物标

· 灯塔 ⚓ / 岛屿 🏝 / 岸形 〰

· 不参与 CPA 计算，仅作方位参照

· 点【样例】一键添加 3 个示例

· 真运动模式下钉在原地不动

⑦ 配色方案

· 经典绿 / FURUNO / INESA 黄 / 夜间红

· 切换后立即生效，无需刷新

⑧ 手机端

· 点【⛶ 全屏 / 横屏】按钮进入全屏

· 手指按住雷达即可拖 EBL / VRM

· 竖屏自动堆叠，横屏左右布局

⑨ 操作要点

· 矢量方向：目标运动方向

· CPA：最近会遇距离（越小越危险）

· TCPA：到达 CPA 的时间（分钟）

· 危险判定：CPA<0.5nm 且 TCPA<10min
